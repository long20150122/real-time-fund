## 一、测试背景

### 问题描述

自选股分类和股票列表没有显示股价和涨跌幅等数据。

### 根因分析

| 数据源 | stock_code 格式 | 示例 |
|--------|----------------|------|
| `watchlist_stocks.csv` | 不带市场前缀 | `300034` |
| `/api/stock-realtime` 返回（修复前） | 带市场前缀 | `sz300034` |

**问题**: `WatchlistContent.jsx` 使用 `realtimeDataMap[stock.stock_code]` 获取实时数据，但由于 key 格式不匹配（`300034` vs `sz300034`），导致无法获取数据。

### 修复方案

修改 `app/api/stock-realtime/route.js`，让返回的 key 使用原始代码（不带市场前缀）。

```javascript
// 修复前
const stockCode = match[1].split('~').pop(); // 返回 "sz300034"

// 修复后
const fullCode = match[1]; // "sz300034"
const stockCode = fullCode.replace(/^(sz|sh|hk|bj)/, ''); // 返回 "300034"
```

## 五、性能分析

### 5.1 `/api/watchlist-stocks` 响应慢的原因

该接口需要：
1. 读取 `watchlist_stocks.csv` 
2. 读取 `stock_history.csv` 获取 RSI 数据
3. 对每只股票进行 RSI 计算

**优化建议**:
- 使用缓存减少文件读取
- 异步并行处理
- 预计算 RSI 数据
