`app/lib` 目录是项目的工具库目录，包含：

1. `csv.js` - CSV 文件操作工具
2. `api.js` - API 工具
3. `dataAccess.js` - 数据访问层
4. `indicators.js` - 指标计算
5. `stockDataUtils.js` - 股票数据工具
6. `stockHistoryService.js` - 股票历史服务
7. `supabase.js` - Supabase 数据库连接
