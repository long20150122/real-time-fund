## [0.1.6] - 2026-02-24

### 新增
- **历史持仓记录与查看**: 记录并展示基金历史持仓变化
  - `data/stocks.csv` - 历史持仓数据存储
  - `crawler/stockSpider.js` - 爬取天天基金历史持仓脚本
  - `app/api/stocks/route.js` - 持仓数据 CRUD API
  - 前端页面添加历史持仓查看弹窗
  - 显示每期持仓及相对上期变化率
  - 新增和移除股票数量标记

### 功能测试报告
| 测试项 | 状态 | 说明 |
|--------|------|------|
| 爬虫脚本 | ✅ 通过 | 成功爬取4个报告期，40条持仓记录 |
| 数据存储 | ✅ 通过 | CSV格式存储，支持A股和港股代码 |
| API接口 | ✅ 通过 | 返回JSON格式，包含变化率计算 |
| 前端页面 | ✅ 通过 | 首页和登录页访问正常 |
| 弹窗组件 | ✅ 通过 | 历史持仓弹窗已集成 |

### 爬虫脚本使用
```bash
# 爬取单个基金
node crawler/stockSpider.js 110011

# 爬取所有基金
node crawler/stockSpider.js --all
```

### 数据示例
基金 110011 易方达优质精选，成功记录4个季度持仓：
- 2025-12-31: 腾讯控股(9.96%)、贵州茅台(9.92%)...
- 2025-09-30: 持仓变化率 0%（持仓稳定）
- 2025-06-30: 持仓变化率 0%
- 2025-03-31: 基期（无对比数据）

## [0.1.5] - 2026-02-24

### 新增
- **CSV 存储系统**: 使用 CSV 文件替代 Supabase 数据库，实现轻量级数据持久化
  - `app/lib/csv.js` - CSV 文件 CRUD 操作工具库
  - `data/users.csv` - 用户数据存储
  - `data/funds.csv` - 用户基金列表存储
  - `data/favorites.csv` - 用户收藏存储
  - `data/configs.csv` - 用户配置存储

- **登录页面**: 新增独立的登录页面 `app/login/page.jsx`
  - 支持账户密码登录
  - 预置账户: `ft` / 密码: `123456`
  - 登录状态存储在 localStorage

- **API 路由**: 新增 CSV 数据操作 API
  - `app/api/users/route.js` - 用户 CRUD
  - `app/api/users/login/route.js` - 登录验证
  - `app/api/funds/route.js` - 基金 CRUD
  - `app/api/favorites/route.js` - 收藏 CRUD
  - `app/api/configs/route.js` - 配置 CRUD

- **API 客户端**: `app/lib/api.js` - 前端 API 调用封装

### 变更
- **数据存储方式**: 从 Supabase 数据库切换为 CSV 文件存储
  - 修改 `app/page.jsx` 中的数据加载逻辑
  - 用户状态管理改为基于 localStorage

- **登录流程**: 
  - 未登录用户自动重定向到 `/login` 页面
  - 登录成功后存储用户信息到 localStorage
  - 退出登录清除 localStorage 并重定向

### 修复
- **登出按钮显示问题**: 修复登录状态下头像下拉菜单仍显示"登录"而非"登出"的问题
  - 原因: useEffect 在检测到 Supabase 未配置时会重置用户状态
  - 解决: CSV 模式下不再重置用户状态，由登录检查逻辑管理

- **登录报错问题**: 修复点击登录按钮报错"未配置 Supabase，无法登录"的问题
  - 修改 `handleOpenLogin` 函数直接跳转到 `/login` 页面

### 移除
- **捐赠支持功能**: 移除捐赠功能及相关代码
  - 删除 `DonateTabs` 组件 (`app/components/Common.jsx`)
  - 删除捐赠弹窗相关代码 (`app/page.jsx`)
  - 删除捐赠图片资源 (`app/assets/zhifubao.jpg`, `app/assets/weixin.jpg`)

- `新增` - 新功能
- `变更` - 现有功能的变更
- `弃用` - 即将删除的功能
- `移除` - 已删除的功能
