## 技术方案设计

### 一、数据库表设计

#### 1. 用户表 `users`
```sql
CREATE TABLE users (
  id VARCHAR(36) PRIMARY KEY,        -- 用户ID (UUID)
  username VARCHAR(50) UNIQUE,       -- 用户名
  email VARCHAR(100) UNIQUE,         -- 邮箱
  password_hash VARCHAR(255),        -- 密码哈希
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);
```

#### 2. 自选分类表 `watchlist_categories`
```sql
CREATE TABLE watchlist_categories (
  id VARCHAR(36) PRIMARY KEY,        -- 分类ID
  user_id VARCHAR(36) NOT NULL,      -- 所属用户
  parent_id VARCHAR(36),             -- 父分类ID (NULL为大分类)
  name VARCHAR(50) NOT NULL,         -- 分类名称
  sort_order INT DEFAULT 0,          -- 排序顺序
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW(),
  
  FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
  FOREIGN KEY (parent_id) REFERENCES watchlist_categories(id) ON DELETE CASCADE
);
```

#### 3. 自选股票表 `watchlist_stocks`
```sql
CREATE TABLE watchlist_stocks (
  id VARCHAR(36) PRIMARY KEY,        -- 记录ID
  user_id VARCHAR(36) NOT NULL,      -- 所属用户
  category_id VARCHAR(36),           -- 所属分类ID (NULL为默认"自选")
  stock_code VARCHAR(10) NOT NULL,   -- 股票代码
  sort_order INT DEFAULT 0,          -- 分类内排序
  added_at TIMESTAMP DEFAULT NOW(),
  
  FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
  FOREIGN KEY (category_id) REFERENCES watchlist_categories(id) ON DELETE SET NULL,
  
  UNIQUE(user_id, stock_code)        -- 同一用户不能重复添加同一股票
);
```
